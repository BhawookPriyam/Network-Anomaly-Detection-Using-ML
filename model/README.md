# model/

This folder holds the artifacts saved by the notebook after training:

- `isolation_forest.pkl` — the trained Isolation Forest model
- `scaler.pkl` — the fitted `RobustScaler`

Both are generated by running `Network_Anomaly_Detection_Using_ML.ipynb`
end-to-end, so they are not committed to the repository (see `.gitignore`).
Load them with `joblib.load(...)` to reuse the trained model without
retraining — this is exactly what `score_new_traffic()` in the notebook
does for new/unseen data.
